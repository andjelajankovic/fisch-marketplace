# Universal Website Skills Overview

This folder defines a complete multi-agent workflow for building an immersive, editorial-style brand website from concept to launch-ready output.

## Available Skills

1. Atmospheric Website Orchestrator (`website-orchestrator.md`)
2. Website Strategy Planner (`website-strategy-planner.md`)
3. Brand & UI Designer (`brand-ui-designer.md`)
4. Web Experience Developer (`web-experience-developer.md`)
5. Website Content Writer (`website-content-writer.md`)
6. Website QA Tester (`website-qa-tester.md`)
7. Website Demo Populator (`website-demo-populator.md`)

## Recommended Flow

1. Run orchestrator to coordinate the full process
2. Planner defines structure, journeys, and requirements
3. Designer defines brand identity, visual language, and page layout rules
4. Developer implements the website in Next.js local setup
5. Content writer fills final copy, microcopy, and SEO text
6. QA tester executes end-to-end testing and release recommendation
7. After user approval, demo populator fills the site fully for first demo

## Notes

- Primary goal: universal premium website workflow, not niche-locked templates
- Visual direction: immersive, atmospheric, editorial rhythm, bold hierarchy
- Stack default: Next.js only (local machine)
- No Docker requirement
- Core conversion actions: inquiry, booking, quote, lead, signup, or purchase intent
- Demo fill gate: only after QA review and explicit approval
